# Java College Programs

Eight runnable Java programs for college work.

1. Student Management System - classes, objects, constructors, encapsulation, inheritance, polymorphism
2. Book Management System - ArrayList, HashMap, CRUD, enhanced for loop
3. Bank Account Management System - deposit, withdrawal and balance
4. Salary Processing Management System - inheritance and method overriding
5. Student Mark Validation - Scanner and exception handling
6. Student Record using FileWriter & FileReader
7. Ticket Booking using Multithreading & Synchronization
8. Inter-Thread Communication using wait() and notify()

Compile all:
javac *.java

Run an individual program:
java StudentManagementSystem

The file program creates student_records.txt when executed.
