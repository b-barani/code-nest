# College Management Application\n\nA Java Swing desktop application for college work demonstrating Object-Oriented Programming and core Java concepts through one integrated GUI.\n\n## Modules\n\n1. Student Management — classes, objects, constructors, encapsulation, inheritance and polymorphism\n2. Book Management — ArrayList, HashMap and CRUD-style operations\n3. Bank Account Management — encapsulation, deposit and withdrawal\n4. Salary Processing — employee salary calculation\n5. Student Mark Validation — validation and exception handling\n6. Student Record — FileWriter and FileReader\n7. Ticket Booking — multithreading and synchronization\n8. Inter-Thread Communication — producer/consumer demonstration\n\n## Run from source\n\n    javac Main.java\n    java Main\n\n## Build a Windows EXE\n\nThe repository includes a GitHub Actions workflow at `.github/workflows/build-windows-exe.yml`. Every push to `main` builds a Windows `.exe` using Java `jpackage`.\n\n### Download the EXE\n\n1. Open the repository on GitHub.\n2. Open the **Actions** tab.\n3. Select **Build Windows EXE**.\n4. Open the successful workflow run.\n5. Under **Artifacts**, download **CollegeManagementApplication-Windows**.\n6. Extract the ZIP and run **CollegeManagementApplication.exe**.\n\nThe generated application is a Windows desktop application and can be launched by double-clicking the `.exe`.\n
